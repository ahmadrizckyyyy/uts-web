DESKRIPSI SINGKAT
Website portal informasi turnamen, jadwal pertandingan, dan pengumuman e-sport berbasis HTML, CSS, dan JavaScript yang mencakup:

1. Halaman Utama: Menampilkan kumpulan informasi perusahaan dan daftar turnamen/event.

2. Halaman Detail Informasi: Menampilkan rincian informasi lengkap saat pengguna memilih salah satu item dari Halaman Utama.

3. Halaman Login: Validasi akun menggunakan fungsi JavaScript dengan struktur percabangan if sebelum berpindah ke Halaman Menu Utama.

4. Halaman Registrasi: Form pendaftaran pengguna baru.

5. Halaman Menu Utama: Halaman dashboard setelah proses login berhasil.

Hasil Pengujian CRUD API (Postman)

1.  Create / Insert Data 
Menambahkan data turnamen baru menggunakan form-data tanpa mengirimkan id.

2.  Read Data
Mengambil seluruh data turnamen dari database MySQL dalam format JSON (200 OK).

3. Update Data 
Memperbarui data turnamen yang sudah tersimpan dengan mengirimkan id target beserta perubahan field-nya.

4. Delete Data
Menghapus data turnamen tertentu berdasarkan id yang dikirimkan.
